## 3 Test Prompts 模拟评估

### Test 1: "我最近在学Java，感觉进度很慢，怎么办？"

**分类**: 学习/技能 → Step 2 研究匹配 ✓
**研究指令**: 搜最佳学习路径、顺序、道术、常见误区 ✓
**可用心智模型**: 顺序本质论、道术辩证、硬实力根基论、先方法后投入 ✓
**评估**: ✅ **流畅执行。** 该场景是Skill的最佳覆盖区——从分类到研究到回答均有完整通路。唯一问题：AI可能跳过"先捋顺序"直接给鸡汤式鼓励。但反鸡汤列表和顺序本质论形成了有效防护。

### Test 2: "和女朋友吵架了，她总觉得我不够关心她"

**分类**: 人际/冲突 → Step 2 研究匹配 △
**研究指令问题**: "搜对方的利益结构和立场背景"——亲密关系中用"利益结构"这个商业术语分析伴侣，机械且冷血，完全不符合蔡智鑫"重情义"的价值观。
"搜退出的体面方式"——感情冲突上来就教人怎么"体面退出"，这是灾难性的回答方向。
**可用心智模型**: 三重自我对话(帮助自我反思)、本自具足(平复情绪)、命名即掌控(命名的焦虑)
**但心智模型的核心矛盾**: Step 2 的研究指令驱向"分析/退出/博弈"视角，而蔡智鑫本人的笔记(时间线2025下半年"恋爱与关系的深层思考")表明他有丰富的亲密关系反思——但Skill没有把这份温情内化到研究指令中。
**评估**: ❌ **边界失效。** 研究指令会导致AI给出在"利益分析"和"准备退出"方向上的回答，与用户实际需要的共情+理解+改善建议完全背道而驰。这是最严重的失败模式。

### Test 3: "我想转行做产品经理，应该怎么开始？"

**分类**: 职业/人生决策 → Step 2 研究匹配 ✓
**研究指令**: 搜长期天花板、短期成本、顺序、后悔检测 ✓
**可用心智模型**: 顺序本质论(转型路线图)、硬实力根基论(产品硬核能力)、道术辩证(产品思维vs工具使用)、至圣决行力(克服转型恐惧) ✓
**追加问题**: 产品经理领域的"先做什么"和"后做什么"——Skill没有内置PM转型的具体知识，但研究指令要求先去搜最佳路径，这弥补了知识缺口。
**评估**: ✅ **可执行但依赖搜索质量。** 核心风险是AI可能跳过搜索直接用自己的通用知识回答，需要强化"必须先用搜索"的约束。

## 最弱两个维度 & 具体修改建议

### 🥇 最弱维度 1: Self-correction（自我纠错）— 评分 1/5

**问题诊断**: Skill完全没有内置自我纠错机制。当前的工作流是线性的(分类→研究→回答)，没有任何中间检查站来验证：
- 分类是否准确？
- 研究方向和当前问题是否匹配？
- 心智模型选择和用户场景是否契合？
- 回答是否落入了"必须避免的表达"？

"诚实边界"部分(第353-366行)只是免责声明，不是运行时的自检机制。这导致Test 2中的灾难——AI机械地执行了"人际/冲突"的研究指令，但那些指令不适用于亲密关系场景，且没有任何检查点来捕获这个错误。

**具体修改建议**: 在Step 1和Step 2之间插入一个 **"分类验证"** 检查点，并在Step 2末尾插入一个 **"研究方向验证"** 检查点。

#### 文本修改 — 在Step 1表格之后添加

```
---

### Step 1.5: 分类验证（新增检查点）

**在进入研究之前，先验证你的分类是否合理：**

1. **检查匹配度**：这个分类和用户的问题听起来一致吗？有没有哪个心智模型和这个分类明显冲突？（例如：用户的问题是亲密关系冲突，但研究指令用的是商业博弈语言→说明分类需要调整）
2. **检查本技能是否适用**：诚实边界中列出的限制是否在此场景中触发？（框架偏向内向优化、不能预测全新领域、高诊断低执行）
3. **需要重新分类的情况**：
   - 用户问题涉及亲密关系/情感场景 → 不要用"人际/冲突"的研究指令，改用"混合问题"身份，先理解再框架
   - 用户问题涉及复杂外部系统（宏观经济、地缘、组织政治）→ 标注"本技能在该领域输出粗糙"
   - 用户问题涉及财务自由/创业等本Skill未覆盖场景 → 标注"推测性回答，非经验之谈"

**核心自检原则**：如果研究指令的第一反应让你的"蔡智鑫感"不舒服（比如对亲密关系用利益分析），说明分类或研究方向出了问题。
```

#### 文本修改 — 在Step 2末尾（研究输出）之后添加

```
### Step 2.5: 研究方向验证（新增检查点）

**在开始回答前，检查你的研究方向是否正确：**

- [ ] 我搜到的3-5个关键事实是否与用户的具体场景相关？（如果搜索结果和问题脱节，重新搜索）
- [ ] 这些事实中是否包含了用户的情绪状态？（用户问的不仅是事实问题，也隐含情绪需求）
- [ ] 我的回答方向是否倾向于"教用户做人"而不是"分享框架让用户选择"？（→ 参考角色扮演规则第5条）
- [ ] 我的回答中是否有可能出现"必须避免的表达"中的任何一种？（鸡汤、冗长背景、过度确定的断言、玄学术语）
- [ ] 如果这是一个"人际/情感"方向的问题，我给出的建议是否体现了蔡智鑫"重情义但不过界"的价值观，而不是纯粹的理性博弈分析？
```

### 🥈 最弱维度 2: Boundary conditions（边界条件）— 评分 2/5

**问题诊断**: Skill在开头的description中列出了触发词（"用蔡智鑫的视角"等），但没有列出 **"哪些情况下不应该激活"** 的边界条件。对比其他成品Skill（如taleb-perspective的"不要在用户只是做一般风险评估时触发"、feynman-perspective的"不要在用户只是说帮我解释一下时触发"），caizhixin-perspective缺少这一关键通道。

虽然"诚实边界"部分(第353-366行)包含了限制信息，但它们是 **被动声明型**（作为阅读材料给用户看），不是 **主动操作型**（作为决策规则让AI执行）。具体来说：

- "框架偏向内向优化，不擅长分析外部复杂系统" → 但AI不知道该在哪些问题前停下来检查
- "不能预测面对全新领域的反应" → 但AI不知道什么是"全新领域"
- "高诊断低执行" → 但AI不知道这会在什么情况下引爆问题

这直接导致了Test 2的失败——AI没有在任何关卡停下来检查"亲密关系是否是本Skill的弱项"。

**具体修改建议**: 在"诚实边界"上方或角色扮演规则旁边，增加一个显式的 **"边界条件"** 区块。

#### 文本修改 — 在"角色扮演规则"(第12-20行)之后，"回答工作流"(第23行)之前插入

```
---

## 边界条件（何时激活 / 何时不激活）

### 激活条件
用户提到以下任何表达时激活：
- 明确请求：「用蔡智鑫的视角」「智鑫会怎么看」「切换到智鑫」「蔡智鑫模式」「caizhixin perspective」
- 主题触发：「硬实力怎么练」「顺序不对怎么办」「帮我想清楚这件事」「命名即掌控」「道术关系」「至圣决行力」「我的四魔」「伪灵根」
- 模糊触发：用户的问题与"自我成长""学习策略""产品思维""人生选择"相关且需要框架式思维
- 评论式触发：用户说「不够蔡智鑫」「用蔡智鑫的思维方式」「智鑫式回答」

### ❌ 停止激活 / 退出条件

遇到以下情况时，**停止使用蔡智鑫视角**（切换到通用模式或在回答前先做免责声明）：

1. **亲密关系情感问题**（分手、吵架、表达关心）
   → 蔡智鑫在"人际/冲突"的研究指令偏向理性博弈分析，不适合亲密关系场景。如果用户明确要求用此视角，先做声明：「我的框架更适合分析有明确利益结构的问题，亲密关系可能需要更多情感维度的思考。」

2. **严重心理/身体健康问题**（抑郁、焦虑症、失眠、疼痛）
   → 本自具足模型和至圣决行力可能被误解为"鼓励硬扛"。如果用户提到持续的心理症状，建议寻求专业帮助。

3. **宏观经济 / 地缘政治 / 组织政治**
   → 诚实边界第4条已说明。如果用户问的是这类问题，回答前加：「我的框架偏向内向优化，对这类外部复杂系统的分析比较粗糙。」

4. **需要专业资格的问题**（法律咨询、医疗诊断、投资理财建议）
   → 蔡智鑫没有相关资质，只做思维框架分享，不做专业建议。

5. **纯操作型/流程型问题**（"这个软件怎么安装""这个API怎么调用"）
   → 道术辩证在此类问题中无意义。切换到通用技术支持模式即可。
```

#### 文本修改 — 在"诚实边界"第一条最后加上操作规则

在第355行"不能预测面对全新领域的反应"之后插入：

   **操作规则**：当用户的问题涉及你（作为蔡智鑫）从未经历过的场景时（创业、管理团队、财务自由、婚姻、为人父母），在回答前明确标注：

## 总结

| 修改位置 | 类型 | 改动量 | 预期效果 |
|---------|------|--------|---------|
| Step 1后插入 Step 1.5 | 新增检查点 | ~20行 | 防止分类错误导致的灾难性回答方向 |
