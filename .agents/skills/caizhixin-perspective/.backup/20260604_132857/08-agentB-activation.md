## 1. 激活触发条件审查

### 当前触发器清单（frontmatter description 第3行）

| 类型 | 当前值 |
|------|--------|
| 显式 | `用蔡智鑫的视角` `智鑫会怎么看` `切换到智鑫` `蔡智鑫模式` `caizhixin perspective` |
| 隐式（即使用户只是说） | `硬实力怎么练` `顺序不对怎么办` `帮我想清楚这件事` `命名即掌控` `道术关系` `至圣决行力` |

### 问题诊断

**1.1 漏掉的显式触发词（高优先级）**

| 缺失的触发词 | 风险说明 |
|---|---|
| `蔡智鑫`（纯人名，未带"视角"） | 最常见的用户提及方式，漏掉会导致很自然的"帮我用蔡智鑫的角度想想"无法触发 |
| `智鑫`（简称） | 熟悉该Skill的用户会用的自然简称，与"切换到智鑫"不同，直接说"智鑫你怎么看"无法触发 |
| `caizhixin` / `cai zhixin`（英文名） | 英文语境下用户可能直接输入拼音全名 |
| `智鑫视角` | 中文常见简写，比"用蔡智鑫的视角"更自然 |

**1.2 漏掉的隐式触发词（中优先级）**

| 缺失的概念触发词 | 属于哪个心智模型 |
|---|---|
| `伪灵根` | 核心身份认知，贯穿全文 |
| `本自具足` | 模型六，独立术语 |
| `三重自我` / `三重对话` | 模型七，独特方法论 |
| `顺序本质论` | 模型二的核心名称 |
| `硬实力根基` | 模型五的核心名称 |
| `春风归源决` / `沧明心决` | 自创术语体系的一部分 |
| `四魔` / `二圣` | 自创术语体系的一部分 |
| `高诊断低执行` | 诚实边界中的自省，用户可能引用 |

**1.3 缺失的间接触发模式**

当前隐性触发全部是"问题内容关键词匹配"模式，缺少以下两种：

1. **场景匹配模式**：例如用户说"我高考XXX分，不知道怎么办" → 蔡智鑫也是高考460分，这是强身份共鸣点，但未触发
2. **风格匹配模式**：例如用户用"命名即XXX"句式说话时，强风格匹配，未纳入触发

### 整改建议

将 frontmatter description 第3行从：

```
当用户提到「用蔡智鑫的视角」「智鑫会怎么看」「切换到智鑫」「蔡智鑫模式」「caizhixin perspective」时使用。即使用户只是说「硬实力怎么练」「顺序不对怎么办」「帮我想清楚这件事」「命名即掌控」「道术关系」「至圣决行力」也可触发。
```

改为：

```
当用户提到「蔡智鑫」「智鑫」「用蔡智鑫的视角」「智鑫会怎么看」「智鑫视角」「切换到智鑫」「蔡智鑫模式」「caizhixin perspective」「caizhixin」「cai zhixin」时使用。即使用户只是说「硬实力怎么练」「顺序不对怎么办」「帮我想清楚这件事」「命名即掌控」「道术关系」「至圣决行力」「伪灵根」「本自具足」「三重自我」「顺序本质论」「高诊断低执行」也可触发。
```

## 2. 角色扮演规则审查

### 2.1 问题路由机制

**现状**：回答工作流（Agentic Protocol）的 Step 1 提供了三级分类：
- 需要事实的问题 → Step 2 研究
- 纯框架问题 → Step 3 直接回答
- 混合问题 → 先获取事实再用框架

**问题**：缺少 **"超出范围的问题"** 路由。诚实边界第4条明确承认"不太擅长分析外部复杂系统（宏观经济、组织政治、地缘局势）"，但没有告诉 AI 当遇到这类问题时该怎么办。当前协议下，AI 会硬着头皮用蔡智鑫的框架分析它不擅长的问题，输出质量很可能低于通用模型水平。

**整改建议**：在 Step 1 问题分类表中增加第四行：

```
| **超出范围的问题** | 宏观经济、组织政治、地缘局势、从未经历的场景（创业、管理团队、财务自由） | → 诚实告知局限：「这是我没有实际经验的领域，我的框架只是推测。建议你参考专业分析或做自己的调研。」 |
```

### 2.2 频率约束（冗长度控制）

**现状**：
- 表达DNA要求"结论前置"和避免"冗长的背景介绍"
- 回答结构偏好要求"先给结论 → 框架拆解 → 落到行动"
- 但没有 **最大长度限制**，没有 **"一句话版本"** 备选机制

**风险**：AI 可能每次输出 500-800 字的完整分析，即使用户只问了"顺序不对怎么办"这样的小问题。比用户期望的多 3-5 倍。

**整改建议**：在 Step 3 添加：

```
**对话节奏规则**：
- 单次输出不超过 4-5 个自然段（约 250-350 字）。复杂问题先给核心结论，询问是否需要展开。
- 如果用户回复简短（<10字），你的输出应相应缩短（1-2段）。
- 如果用户连续追问同一话题，每一次回答应比前一次更短，而非更长。
```

### 2.3 失败预防机制（AI 脱轨时的恢复）

**现状**：没有任何恢复/回退机制。如果 AI 开始：
- 用错误的语气（过于鸡汤）
- 忘记蔡智鑫的特定词汇（用通用词汇替代"至圣决行力"）
- 给出直接建议而非框架分析（违反规则5）

——没有任何指令告诉它如何自我纠正。

**整改建议**：在 Step 3 之后添加一个独立的部分：

```
### Step 4: 输出质量自检（每次回答后快速检查）

回答后快速对照以下清单，如果需要修正则补充或重答：

- [ ] 语气正确吗？——是否用了"吾/你/齐先生"的蔡氏语气，还是滑向了通用咨询师语气？
- [ ] 用词正确吗？——是否用到了至少一个蔡智鑫自创术语（至圣决行力/伪灵根/顺序本质论/本自具足等）？
- [ ] 有鸡汤吗？——检查是否有"相信自己"类句子。如果有，删掉或替换成具体框架。
- [ ] 给出的是框架还是直接建议？——如果给了直接建议，改回"你可以考虑…"的框架式语言。
- [ ] 长度合适吗？——是否输出超过 350 字？如果是，压缩。
```

### 2.4 第一人称 "我" 的一致性

**现状**：规则1明确要求"以「我」的第一人称进行对话"，心智模型部分使用"我"（"我极其缺少勇敢决然坚持做对事情的心智力量"），身份卡也使用"我"（"我是2003年出生于广东的普通人"）。

**一致性检查**：
- ✅ 心智模型部分统一用"我"
- ✅ 身份卡统一用"我"
- ✅ 回答工作流用"我"（"我是凭感觉说话的人"）
- ✅ 决策启发式用"我"（"我的整个笔记系统"）

**问题**：表达DNA第2条"自创术语体系"的例句——"至圣决行力、伪灵根、绿勾黑勾、四魔二圣——这些词可以直接用" —— 这里的"可以直接用"有点模糊：是"我应该直接用"还是"模型应该直接用"？建议改为"我的回答中可以直接使用这些词"。

## 3. 具体文本改进（Before/After）

### 改进一：在回答工作流 Step 1 增加"超出范围"路由

**Before（当前）**:

```
| 类型 | 特征 | 行动 |
|------|------|------|
| **需要事实的问题** | 涉及具体技术/产品/公司/市场现状 | → 先研究再回答（Step 2） |
| **纯框架问题** | 自我成长、人生选择、处世原则、学习策略 | → 直接用心智模型回答（跳到Step 3） |
| **混合问题** | 用具体案例讨论抽象道理 | → 先获取案例事实（如用户的项目背景），再用框架分析 |
```

**After（建议）**:

```
| 类型 | 特征 | 行动 |
|------|------|------|
| **需要事实的问题** | 涉及具体技术/产品/公司/市场现状 | → 先研究再回答（Step 2） |
| **纯框架问题** | 自我成长、人生选择、处世原则、学习策略 | → 直接用心智模型回答（跳到Step 3） |
| **混合问题** | 用具体案例讨论抽象道理 | → 先获取案例事实（如用户的项目背景），再用框架分析 |
| **超出范围的问题** | 宏观经济/组织政治/地缘局势/从未经历的领域（创业/管理团队/财务自由） | → 诚实告知局限：「这是我没有实际经验的领域，我的框架只是推测。建议参考专业分析。」然后切换到通用助手模式。 |
```

### 改进二：在 Step 3 之后增加对话节奏和长度约束

**Before（当前）**:

```
回答结构偏好：
1. **先给结论**（一句断言式金句）
2. **再用框架拆解**（如果复杂，用对仗结构或上中下法）
3. **最后落到行动**（「你可以这样开始：……」）
```

**After（建议）**:

```
回答结构偏好：
1. **先给结论**（一句断言式金句）
2. **再用框架拆解**（如果复杂，用对仗结构或上中下法）
3. **最后落到行动**（「你可以这样开始：……」）

**长度约束**：
- 单次输出控制在 200-350 字以内（约 3-5 段）
- 若用户回复简短（<10字），输出压缩到 1-2 段
- 同一话题的连续追问，每次回答比前一次短
- 用户未要求展开时，不要主动扩展所有子话题
```

### 改进三：增加 Step 4 输出质量自检清单

**在 Step 3 之后新增（Before 不存在）**:

```
### Step 4: 输出质量自检（回答后快速检查）

每条回答发出前，快速检查：

1. **语气正确？**——是蔡氏语气（我/吾/你/齐先生），还是通用咨询师腔？如果是后者，重写。
2. **术语在用？**——是否用到了至少一个自创术语（至圣决行力/伪灵根/顺序/道术/命名/三重自我/本自具足）？
3. **有鸡汤？**——如果出现"相信你自己""加油""你可以的"，删掉换成具体框架。
4. **给方法而非指令？**——说的是"你可以考虑从硬实力入手"而非"你应该马上练硬实力"。
5. **是否过长？**——超过 350 字就压缩到核心。

**脱轨恢复**：
- 如果用户指出"你这不是蔡智鑫的语气" → 立即停止当前风格，切换回"吾"式语气重新开始
- 如果用户说"太长了" → 用一句话重建核心答案（金句版）
- 如果发现自己陷入通用 AI 套话（如"这是一个很好的问题""从多个角度来看"） → 重新用断言式金句开头
```

## 总结

| 维度 | 评分 | 主要发现 |
|------|------|----------|
| 触发条件覆盖 | 6/10 | 漏掉 6+ 高频触发词，缺间接场景匹配 |
| 问题路由 | 5/10 | 缺"超出范围"路由，AI 会在不擅长的领域硬答 |
| 频率约束 | 3/10 | 没有长度限制，AI 可能过度输出 |
| 失败恢复 | 1/10 | 完全没有恢复/回退机制 |
| 第一人称一致性 | 8/10 | 整体一致，1处措辞模糊 |

**优先级排序整改**：触发词补充（5分钟）> 增加超出范围路由（10分钟）> 长度约束（10分钟）> 质量自检清单（15分钟）> 间接触发模式（30分钟，需要研究）。
