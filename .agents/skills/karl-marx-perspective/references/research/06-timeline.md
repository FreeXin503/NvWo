# 卡尔·马克思生平时间线

## 早期生活与教育（1818-1843）

| 年份 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1818年5月5日 | 出生于普鲁士莱茵省特利尔市 | 犹太裔家庭背景，父亲是律师，母亲是家庭主妇 |
| 1830年 | 进入特利尔中学 | 开始接触启蒙思想和法国大革命文献 |
| 1835年 | 中学毕业，进入波恩大学学习法律 | 对哲学产生兴趣 |
| 1836年 | 转入柏林大学 | 加入青年黑格尔派，研究黑格尔哲学 |
| 1841年 | 获得哲学博士学位，论文《德谟克利特的自然哲学和伊壁鸠鲁的自然哲学的差别》 | 确立学术基础，但仍受黑格尔唯心主义影响 |
| 1842年 | 担任《莱茵报》主编 | 接触现实社会问题，开始关注经济和政治 |
| 1843年 | 《莱茵报》被查封，与燕妮·冯·威斯特华伦结婚 | 思想开始转向唯物主义 |

## 思想转变与理论构建（1844-1848）

| 年份 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1844年 | 流亡巴黎，与恩格斯相遇 | 开始终身合作，共同创立马克思主义 |
| 1844年 | 撰写《1844年经济学哲学手稿》 | 提出异化劳动理论，人本主义思想 |
| 1845年 | 撰写《关于费尔巴哈的提纲》 | 确立实践唯物主义立场 |
| 1845-1846年 | 与恩格斯共同撰写《德意志意识形态》 | 系统阐述历史唯物主义 |
| 1847年 | 撰写《哲学的贫困》 | 批判蒲鲁东，完善政治经济学理论 |
| 1848年 | 发表《共产党宣言》 | 马克思主义诞生，明确无产阶级革命纲领 |

## 革命实践与流亡（1848-1850）

| 年份 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1848年 | 欧洲革命爆发，回到德国创办《新莱茵报》 | 直接参与革命实践 |
| 1849年 | 《新莱茵报》被查封，流亡伦敦 | 开始长期流亡生活 |
| 1850年 | 撰写《1848年至1850年的法兰西阶级斗争》 | 总结革命经验，发展阶级斗争理论 |

|------|------|--------------|

## 关键思想发展阶段

1. **黑格尔主义阶段（1836-1843）**
   - 受黑格尔哲学影响，信仰唯心主义
   - 关注精神现象学和辩证法

2. **费尔巴哈阶段（1843-1845）**
   - 转向唯物主义
   - 批判宗教和唯心主义

3. **历史唯物主义阶段（1845-1848）**
   - 创立历史唯物主义
   - 强调经济基础决定上层建筑

4. **政治经济学阶段（1848-1867）**
   - 深入研究政治经济学
   - 建立剩余价值理论

5. **革命实践阶段（1864-1883）**
   - 领导国际工人运动
   - 总结革命经验

## 重要人际关系

1. **燕妮·冯·威斯特华伦**（妻子）
   - 贵族出身，支持马克思的革命事业
   - 陪伴马克思走过艰难的流亡岁月

2. **弗里德里希·恩格斯**（挚友与合作者）
   - 共同创立马克思主义
   - 在经济上和学术上支持马克思

3. **威廉·李卜克内西**（学生与同志）
   - 德国社会民主党创始人
   - 传播马克思主义思想

4. **保尔·拉法格**（学生与女婿）
   - 法国工人运动领袖
   - 宣传马克思主义理论
