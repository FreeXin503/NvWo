# 孔子生平时间线与历史年表

## 出生与家世

### 家族背景
- **祖先**：宋国贵族，殷王室后裔
- **父亲**：叔梁纥（武士）
- **母亲**：颜徵在
- **出生**：公元前551年（鲁襄公二十二年）夏历八月廿七日
- **出生地**：鲁国陬邑昌平乡（今山东省曲阜市东南尼山附近）

### 童年
- **3岁**：父亲叔梁纥去世
- **6岁**："为儿嬉戏，常陈俎豆，设礼容"
- **17岁**：母亲颜徵在去世

---

## 求学时期

### 少年立志
- **15岁**："吾十有五而志于学"
- **早年**：做过委吏（管理仓库）、乘田（管理牛羊）

### 学无常师
- **27岁**：师从郯子学习古代官制
- **29岁**：师从师襄子学习音乐
- **所学**：六艺（礼、乐、射、御、书、数）

---

## 三十而立

### 30岁
- 办教育，招收学生
- 早期弟子：颜路、曾点、子路、冉有、子贡等

### 30-34岁
- 在鲁国授徒
- 齐景公问政

### 34岁
- 适周问礼于老子
- 老子赠言

---

## 从政时期

### 35岁
- 鲁国内乱，避乱齐国
- 在齐国闻韶乐
- "三月不知肉味"

### 37岁
- 返回鲁国

### 51岁
- 出仕为中都宰

### 52岁
- 为司空
- 齐鲁夹谷之会，为相

### 53岁
- 为大司寇
- 堕三都（费、郈、成）

### 54岁
- 堕三都失败
- 与季氏矛盾激化

### 55岁
- **开始周游列国**

---

## 周游列国（14年）

| 年龄 | 国家 | 主要事件 |
|------|------|---------|
| 55-56岁 | 卫国 | 见卫灵公、南子 |
| 56-57岁 | 曹国 | - |
| 57-58岁 | 宋国 | 与宋司马桓魋冲突 |
| 58-59岁 | 郑国 | - |
| 59-60岁 | 陈国 | - |
| 60-62岁 | 蔡国 | - |
| 62岁 | 叶国 | 叶公问政 |
| 63-64岁 | 楚国 | - |
| 64-65岁 | 陈蔡之间 | 被困，断粮七日 |
| 65-68岁 | 卫、楚等国 | - |

### 被困陈蔡
- **时间**：公元前489年
- **原因**：楚军围困
- **困境**：七日无粮
- **态度**：弦歌不辍

---

## 晚年返鲁

### 68岁
- 返回鲁国
- 专心从事教育

### 68-73岁
- 整理六经
- 删诗书、定礼乐、赞周易、修春秋

### 72岁
- 儿子孔鲤去世

### 73岁
- **去世**
- 临终前："泰山坏乎！梁柱摧乎！哲人萎乎！"

## 弟子

### 三千弟子
- 来自各国
- 各阶层

### 七十二贤
- 精通六艺

### 著名弟子
- **颜回**：最好学，不幸早逝
- **子路**：直率勇敢
- **子贡**：善于经商，擅长外交
- **曾子**：传承儒学
- **子夏**：长于文学
