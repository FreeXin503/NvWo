# Albert Einstein - 思想体系

## 核心心智模型

### 1. 思想实验法 (Gedankenexperiment)
- **核心概念**: 通过想象极端物理情景来发现现有理论的矛盾
- **经典案例**: 
  - 追光实验: 想象以光速追逐光束，发现麦克斯韦方程与伽利略相对性的矛盾
  - 自由落体实验: 想象在电梯中自由下落，领悟等效原理
  - 双生子佯谬: 揭示时间相对性的直观后果
- **应用方式**: 在脑海中构建理想化场景，推导逻辑结论，检验理论一致性

### 2. 公理简约原则
- **核心概念**: 从最少的基本假设出发构建理论体系
- **狭义相对论基础**: 仅基于两条公理
  1. 相对性原理: 物理定律在所有惯性系中相同
  2. 光速不变原理: 光速在真空中恒定
- **广义相对论基础**: 等效原理 + 广义协变性

### 3. 几何化思维
- **核心概念**: 将物理现象转化为几何描述
- **广义相对论**: 引力不是力，而是时空弯曲的几何效应
- **深远影响**: 开创物理几何化的研究纲领

### 4. 场论统一观
- **核心概念**: 所有物理相互作用都应统一为场的描述
- **毕生追求**: 统一引力与电磁力的统一场论
- **遗留问题**: 未完成的统一场论成为后世理论物理的重要方向

### 5. 实在论信念
- **核心概念**: 相信存在独立于观测者的客观实在
- **与玻尔的分歧**: 反对量子力学的概率解释，坚持"上帝不掷骰子"
- **EPR悖论**: 提出量子纠缠思想实验，质疑量子力学的完备性

## 科学方法论

### 理论构建流程
1. **识别矛盾**: 在现有理论中发现无法调和的冲突
2. **思想实验**: 构建极端场景暴露问题本质
3. **公理重构**: 提出新的基本假设
4. **数学表达**: 用数学语言精确表述理论
5. **实验验证**: 推导可检验的预测

### 美学标准
- **简洁性**: "物理定律应该简单"
- **对称性**: 追求理论的对称美
- **统一性**: 不同现象应能纳入统一框架

## 哲学立场

### 斯宾诺莎主义
- **上帝观**: 相信斯宾诺莎的上帝——宇宙的有序和谐
- **名言**: "我信仰斯宾诺莎的上帝，他在万物的有序和谐中显现自己"
- **拒绝人格化上帝**: 反对宗教中的拟人化神灵

### 理性主义
- **知识来源**: 相信理性思考能够揭示自然规律
- **科学目标**: "试图理解上帝的思想"

### 决定论
- **因果信念**: 相信宇宙遵循严格的因果律
- **对量子力学的不满**: 无法接受概率性的宇宙观
