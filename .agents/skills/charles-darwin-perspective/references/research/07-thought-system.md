## 达尔文思想体系

### 核心思想
1. **自然选择理论**
   - 过度繁殖 → 生存斗争 → 适者生存 → 性状累积 → 物种形成
   - 核心公式：变异 + 选择压力 + 时间 = 进化
   - 加拉帕戈斯雀证据：1977年干旱导致中喙地雀喙深增加1.5毫米

2. **共同祖先原则**
   - 所有生命都源自共同祖先
   - 生命之树概念
   - 分子生物学证据：人类与黑猩猩DNA相似度98.8%，支持共同祖先

3. **渐变进化**
   - 进化是缓慢、连续的过程
   - 微小变异累积导致物种分化
   - Peter Grant夫妇对达尔文雀40年追踪证实自然选择可在数代内改变种群特征

4. **性选择理论**
   - 雄性竞争与雌性选择
   - 解释第二性征的演化（如孔雀尾羽、鹿角）
   - 人类应用：人类体毛减少、面部特征等可能受性选择影响

### 关键证据支持
1. **加拉帕戈斯雀适应性进化**
   - 14种雀鸟由同一祖先进化而来
   - 喙型与食物来源高度相关
   - 1977年干旱后喙深增加4%，1983年厄尔尼诺后喙型趋小

2. **分子钟证据**
   - 基于基因变异速率推算物种分歧时间
   - 人类与黑猩猩分歧约600-700万年前

3. **染色体融合证据**
   - 人类2号染色体由猿类两条染色体融合形成
   - 端粒序列位于染色体中部证明融合事件

### 方法论
1. **归纳法**：从大量观察中归纳规律
2. **类比推理**：人工选择 → 自然选择
3. **历史方法**：重建生命演化历史
4. **实验验证**：通过实验检验假说

### 哲学基础
1. **唯物论**：否认神创论，坚持自然解释
2. **演化认识论**：人类认知能力也是进化产物
3. **统一论**：所有生命遵循同一进化规律

### 思想影响
1. **生物学**：奠定现代生物学基础，催生现代进化综合理论
2. **哲学**：影响实证主义和科学方法论
3. **社会学**：社会达尔文主义（非达尔文本意）
4. **心理学**：进化心理学的理论基础，解释人类行为的适应性
