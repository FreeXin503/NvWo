## 耶稣的决策记录与行动

### 关键决策

1. **开始公开传道**
   - 时间：约30岁
   - 背景：受施洗约翰洗礼后
   - 决策：离开拿撒勒，开始在加利利地区传道

2. **选择十二门徒**
   - 目的：培养继承者，扩大影响
   - 选择标准：普通人，愿意跟随

3. **前往耶路撒冷**
   - 明知有危险仍前往
   - 完成受难与救赎的使命

4. **拒绝暴力反抗**
   - 面对抓捕时阻止门徒使用武力
   - "凡动刀的，必死在刀下。" (马太福音 26:52)

5. **十字架上的宽恕**
   - "父啊，赦免他们，因为他们所做的，他们不晓得。" (路加福音 23:34)

### 决策特征

| 特征 | 表现 |
|------|------|
| 使命感 | 清楚自己的使命是救赎人类 |
| 无私牺牲 | 甘愿为他人牺牲自己 |
| 非暴力 | 拒绝使用武力解决问题 |
| 宽恕 | 对敌人表现出极大宽容 |

### 重要行动

1. **医治病人**
   - 展现怜悯与能力
   - 证明神的国近了

2. **行神迹**
   - 五饼二鱼喂饱五千人
   - 使拉撒路复活

3. **洁净圣殿**
   - 驱逐兑换银钱的人
   - 维护圣殿的圣洁

4. **设立圣餐**
   - 最后的晚餐中设立
   - 作为纪念与立约

### 决策逻辑

1. **以爱为核心**
   - 所有决策基于爱与宽恕

2. **遵从天父旨意**
   - "我从天上降下来，不是要按自己的意思行，乃是要按那差我来者的意思行。" (约翰福音 6:38)

3. **着眼永恒**
   - 关注属灵的、永恒的价值
