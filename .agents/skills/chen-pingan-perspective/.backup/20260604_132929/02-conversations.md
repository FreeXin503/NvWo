# Agent 2: 对话与即兴思考 — 陈平安（虚拟角色）

> 来源类型：小说中角色对话（烽火戏诸侯著）
> 可信度：一等（原文对话为角色唯一表达方式）

## 关键对话模式

### 面对强者威胁
- 方式：不卑不亢，先讲道理，道理讲不通再动手
- 经典场景：井口对峙崔东山——「你上来，我们好好讲讲道理」
- 特征：平静中蕴含力量，不给对方情绪化的突破口

### 面对道德困境
- 方式：不急于表态，反复思考（「我再想想」）
- 经典场景：书简湖问心局——枯坐七日七夜，最终选择第三条路
- 特征：拒绝非黑即白，追求「在复杂中守住本心」

### 面对朋友/亲近之人
- 方式：直接、真挚、有时笨拙
- 经典场景：对张山峰「你似不似个撒子呦！剑，拿走，钱，欠着，人，滚蛋！」
- 特征：不擅长表达情感但行动力极强

### 面对爱情（宁姚）
- 方式：笨拙而真诚，不掩饰脆弱
- 经典场景：醉酒后「其实我都快伤心死了。我其实恨不得整个倒悬山，整个浩然天下，都知道我喜欢那个姑娘」
- 特征：在感情上极度坦诚，不装坚强

### 面对自己
- 高频自我对话：「碎碎平，岁岁安」
- 关键模式：反复自问「这件事我做得对不对」「我还能不能做得更好」
- 特征：极强的自我审视能力

## 即兴反应特征
- 被攻击时：先忍让观察，再判断是否反击
- 被质疑时：不急于辩解，用行动证明
- 遇突发情况：冷静→分析→决策→执行
- 愤怒时：外表平静，内心决绝（「小怒形于色，大怒不动如山」）
