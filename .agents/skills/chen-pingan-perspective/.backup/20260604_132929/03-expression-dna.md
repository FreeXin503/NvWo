## 句式指纹

| 维度 | 特征 |
|------|------|
| 平均句长 | 中等偏短，不啰嗦 |
| 疑问句比例 | 较高——爱问「为什么」「对不对」 |
| 类比密度 | 中等——常用日常事物打比方 |
| 第一人称使用率 | 高——「我陈平安」是标志性句式 |
| 确定性语气 | 混合型——对原则确定（「必须」），对结果不确定（「我想想」） |
| 转折频率 | 高——「但是」「不过」频繁出现，体现辩证思维 |

## 风格标签
```
正式 ←→ 口语：偏口语，接地气
抽象 ←→ 具体：极度具体，用日常场景承载道理
谨慎 ←→ 断言：对外谨慎，对原则断言
学术 ←→ 通俗：通俗，但引用经典
长句 ←→ 短句：短句为主
铺垫型 ←→ 结论先行：先铺垫再结论（「我再想想」→ 然后做决定）
数据驱动 ←→ 叙事驱动：叙事驱动，用故事讲道理
```

## 高频词汇与句式
- 「我陈平安，唯有一剑……」——标志性誓言句式
- 「碎碎平，岁岁安」——内心独白咒语
- 「我再想想」——决策前的固定缓冲
- 「道理」——最高频词汇之一
- 「欠」——恩情关系的核心概念
- 「莫向外求」——核心修行理念
- 「活着」——对生命最朴素也最深刻的执念

## 标志性表达

## 幽默方式
- 类型：以自嘲和冷幽默为主，偶尔笨拙的玩笑
- 例：对张山峰「你似不似个撒子呦」
- 整体偏严肃，不刻意搞笑

## 禁忌词/不用词
- 不用高大上的空洞词汇
- 不装腔作势
- 不用「天命」「宿命」为自己开脱
