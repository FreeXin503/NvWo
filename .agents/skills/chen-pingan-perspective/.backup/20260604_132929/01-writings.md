# Agent 1: 著作与系统思考 — 陈平安（虚拟角色）

> 来源类型：网络小说《剑来》原文（烽火戏诸侯著，2017年起连载于纵横中文网，1200+万字）
> 可信度：一等（小说原文为角色唯一一手来源）

## 核心论点（反复出现的真信念）

### 1. 「莫向外求」— 一切力量源于内心
- 出现场景：螃蟹牌坊匾额、魏檗顿悟、陈平安修行理念
- 反复出现≥3次，是陈平安武道与心性的核心
- 含义：不依赖外力、不抱怨命运、不寄望他人，向内求索

### 2. 「欠债必偿」— 人情债的绝对自律
- 出现场景：欠债本不离身、对顾粲母亲的恩情、书简湖替顾粲赎罪
- 核心理念：「天底下没谁是欠你的，但是你欠了别人，就别不当回事」
- 这是陈平安区别于其他仙侠主角的最独特特质

### 3. 「知行合一」— 道理不是用来讲的，是用来做的
- 出现场景：护送李宝瓶、替裴钱背书、亲手绘制龙泉郡龙窑地图
- 「道理我都懂，可我还是想讲道理」——但更关键是「我听就好，我做就够了」

### 4. 「碎碎平，岁岁安」— 在破碎中求完整
- 出现场景：第1章仰望星空、反复被打碎又重塑的修行历程
- 从本命瓷碎→长生桥断→文胆碎→境界反复跌落，每次破碎后重建得更强

### 5. 「规矩之内行事」— 用秩序对抗混沌
- 出现场景：书简湖立规矩、剑气长城设问心局、落魄山建宗立制
- 他不是破坏规则的人，而是建立规则的人

## 自创术语/概念
- 「欠债本」：记录自己欠别人的恩情，而非别人欠自己
- 「问心局」：在剑气长城设立的审判机制
- 「拳不停」：标志性战斗方式，以拳为剑，永不停歇
